    All numbers

    Read this before quoting

    • Synthetic test set of 149 messages written by one person with templated wording. It does not show production accuracy, and one message is about 0.7 points.
    • One run per system; run-to-run variance is unknown.
    • Laya is fine-tuned on 640 messages from the same author and templates. Jev and the LLM classifier are used as provided, with no fine-tuning, so this is not an equal-effort comparison.
    • Latency compares different deployments: Laya on a local CPU, Jev over the network, the LLM through a local client with its own start-up overhead. Treat it as a rough indication only.
    • The model is not the whole safety story. Refund amounts and policy windows belong in ordinary code.
    Laya: Nandha Kishore M and Convai Innovations, open source (Apache 2.0). Jev: TypeSafe AI, hosted. Figures come from data/results.json, produced by run_arms.py and the Laya fine-tuning repo.
